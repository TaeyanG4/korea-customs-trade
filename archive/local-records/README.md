# Local records archive

Small, non-reproducible or hard-to-recover records copied from git-ignored local
working directories (release manifests, Kaggle dataset/notebook metadata, QA and
build reports) before the local working copy was cleaned up on 2026-10-01.

Paths below this folder mirror the original project-relative paths. Bulk data
(raw downloads, processed tables, release files, images) is intentionally not
stored here: rebuild it with the pipeline in this repository or download the
published dataset from Kaggle. Secrets (`.env`) are never committed.
